# قائمة فحص أخطاء Indentation في Python

إذا ظهر لك خطأ في المسافات البادئة، راجع هذه النقاط:

- هل السطر السابق ينتهي بعلامة `:`؟
- هل أضفت 4 مسافات قبل السطر التابع للشرط أو الحلقة أو الدالة؟
- هل كل الأسطر داخل نفس الكتلة على نفس مستوى المسافة؟
- هل يوجد سطر مزاح للداخل بدون سبب؟
- هل خلطت بين Tab و Space؟
- هل نسخت الكود من الإنترنت وظهرت مسافات غريبة؟
- هل محرر الكود مضبوط على تحويل Tab إلى Spaces؟
- هل جربت فحص الملف باستخدام:

```bash
python -m tabnanny yourfile.py
```

## تذكير

أغلب أخطاء `IndentationError` سببها مسافة ناقصة أو زائدة في بداية السطر.
