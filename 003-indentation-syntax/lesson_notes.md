# ملاحظات الدرس

## ما هي المسافة البادئة Indentation؟

المسافة البادئة هي الفراغ الموجود في بداية السطر.  
في Python تستخدم هذه المسافة لتحديد أن السطر تابع لكتلة معينة من الكود.

مثال:

```python
if age >= 18:
    print("Allowed")
```

سطر `print` تابع للشرط لأنه مزاح للداخل.

## القاعدة الذهبية

إذا كان السطر ينتهي بعلامة النقطتين `:`، فغالبًا السطر التالي يحتاج إلى مسافة بادئة.

أمثلة على أسطر تحتاج كتلة بعدها:

```python
if x > 5:
for item in items:
def say_hello():
while True:
```

## عدد المسافات المناسب

الأسلوب الشائع في Python هو استخدام 4 مسافات لكل مستوى.

```python
if True:
    print("Level 1")
    if True:
        print("Level 2")
```

## أخطاء شائعة

### 1. نسيان المسافة البادئة

```python
if 5 > 2:
print("Wrong")
```

### 2. مسافة زائدة في مكان غير مناسب

```python
print("Start")
    print("Wrong")
```

### 3. خلط Tab مع Space

قد يعمل الكود أحيانًا ثم يتعطل لاحقًا. الأفضل استخدام Spaces فقط.

## أداة مفيدة

```bash
python -m tabnanny yourfile.py
```
