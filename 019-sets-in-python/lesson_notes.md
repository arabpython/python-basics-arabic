# ملاحظات الدرس

## ما هي Set؟

`Set` نوع بيانات في Python يستخدم لتخزين مجموعة من العناصر داخل متغير واحد.

```python
numbers = {1, 2, 3, 3, 4}
print(numbers)
```

الناتج سيكون بدون تكرار:

```text
{1, 2, 3, 4}
```

## أهم فكرة

`Set` لا تسمح بتكرار العناصر.  
إذا أضفت نفس العنصر أكثر من مرة، سيبقى مرة واحدة فقط.

## إنشاء Set

```python
fruits = {"apple", "banana", "orange"}
print(fruits)
```

قد يظهر ترتيب العناصر عند الطباعة مختلفًا عن ترتيب كتابتها، وهذا طبيعي.

## إنشاء Set فارغة

لا تستخدم `{}` لإنشاء Set فارغة، لأن هذا ينشئ Dictionary فارغًا.

```python
x = {}
print(type(x))  # dict
```

الصحيح:

```python
x = set()
print(type(x))  # set
```

## هل Set تحفظ الترتيب؟

لا تعتمد على ترتيب عناصر Set.  
إذا كان الترتيب مهمًا، استخدم `List`.

## هل يمكن استخدام index مع Set؟

لا، Set لا تدعم الوصول باستخدام index.

```python
fruits = {"apple", "banana", "orange"}
# print(fruits[0])  # TypeError
```

## الإضافة والحذف

```python
fruits.add("mango")
fruits.update(["orange", "kiwi"])

fruits.remove("apple")   # يسبب خطأ إذا لم يكن العنصر موجودًا
fruits.discard("apple")  # لا يسبب خطأ إذا لم يكن العنصر موجودًا
```

## فحص وجود عنصر

```python
if "apple" in fruits:
    print("العنصر موجود")
```

## إزالة التكرار من List

```python
numbers = [1, 2, 2, 3, 3, 4]
unique_numbers = set(numbers)
print(unique_numbers)
```

ولو أردت النتيجة كقائمة:

```python
unique_numbers_list = list(set(numbers))
```

لكن انتبه: التحويل إلى Set قد لا يحافظ على نفس الترتيب.

## الفرق بين List و Tuple و Set

| النوع | يقبل التكرار؟ | يحافظ على الترتيب؟ | قابل للتعديل؟ |
|---|---|---|---|
| List | نعم | نعم | نعم |
| Tuple | نعم | نعم | لا |
| Set | لا | لا تعتمد عليه | نعم |

## عمليات Set المهمة

```python
a.union(b)         # دمج مجموعتين بدون تكرار
a.intersection(b)  # العناصر المشتركة
a.difference(b)    # العناصر الموجودة في a وليست في b
```

## متى تستخدم Set؟

استخدم Set عندما:

- تريد إزالة العناصر المكررة.
- تريد معرفة العناصر المشتركة بين مجموعتين.
- تريد معرفة العناصر المختلفة بين مجموعتين.
- تريد فحص وجود عنصر بسرعة.
- لا يهمك ترتيب العناصر.

## متى لا تستخدم Set؟

لا تستخدم Set عندما:

- تحتاج ترتيب العناصر.
- تحتاج الوصول باستخدام index.
- تريد السماح بالتكرار.
- تريد تخزين بيانات على شكل key و value، استخدم Dictionary في هذه الحالة.
