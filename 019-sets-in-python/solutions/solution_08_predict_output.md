# حل تمرين 08

الناتج المنطقي هو:

```text
4
True
False
{'a', 'b', 'c', 'd'}
```

## ملاحظة مهمة

ترتيب عناصر `set` عند الطباعة قد يختلف من تشغيل لآخر، لذلك المهم هنا هو وجود العناصر وعددها، وليس ترتيبها.

## السبب

- `items` بدأت بـ `{"a", "b", "a", "c"}`، لكن التكرار يحذف، فتبقى `a`, `b`, `c`.
- `add("d")` تضيف `d`.
- `discard("x")` لا تسبب خطأ حتى لو أن `x` غير موجود.
- العدد النهائي 4.
