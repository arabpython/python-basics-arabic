# قائمة فحص أسماء المتغيرات في بايثون

قبل اختيار اسم متغير، راجع هذه النقاط:

- هل يبدأ الاسم بحرف أو شرطة سفلية `_`؟
- هل تجنبت بدء الاسم برقم؟
- هل الاسم لا يحتوي على مسافات؟
- هل الاسم لا يحتوي على رموز خاصة؟
- هل تجنبت الكلمات المحجوزة مثل `if`, `for`, `class`؟
- هل الاسم واضح ويشرح القيمة؟
- هل استخدمت Snake Case مثل `student_name`؟
- هل انتبهت أن `age` و `Age` و `AGE` أسماء مختلفة؟

## أسماء جيدة

```python
student_name = "Ali"
total_score = 95
user_age = 20
```

## أسماء سيئة

```python
n = "Ali"
my score = 95
2age = 20
```
