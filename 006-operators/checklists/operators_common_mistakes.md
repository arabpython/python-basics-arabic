# قائمة أخطاء شائعة في معاملات بايثون

راجع هذه النقاط عند استخدام Operators:

## 1. الخلط بين = و ==

```python
x = 5      # إسناد
x == 5     # مقارنة
```

## 2. استخدام is بدل ==

استخدم `==` عندما تريد مقارنة القيم.

```python
a == b
```

واستخدم `is` عندما تريد معرفة هل المتغيران يشيران إلى نفس الكائن في الذاكرة.

## 3. القسمة على صفر

```python
x / 0
```

هذا يسبب:

```text
ZeroDivisionError
```

## 4. دمج نص مع رقم باستخدام +

```python
age = 20
print("Age: " + age)
```

الحل:

```python
print("Age: " + str(age))
```

أو الأفضل:

```python
print(f"Age: {age}")
```

## 5. نسيان الأقواس في العمليات المركبة

```python
print(2 + 3 * 4)      # 14
print((2 + 3) * 4)    # 20
```

## 6. عدم فهم / و //

```python
print(13 / 4)    # 3.25
print(13 // 4)   # 3
```
