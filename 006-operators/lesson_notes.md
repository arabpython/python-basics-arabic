# ملاحظات الدرس

## ما هي العوامل Operators؟

العامل هو رمز أو كلمة تنفذ عملية على قيمة أو أكثر.

مثال:

```python
print(10 + 5)
```

هنا `+` هو العامل، و `10` و `5` هما القيمتان أو Operand.

## 1. العوامل الحسابية

```python
+   جمع
-   طرح
*   ضرب
/   قسمة عادية
//  قسمة صحيحة
%   باقي القسمة
**  أس
```

## 2. عوامل الإسناد

```python
x = 10
x += 5
x *= 2
```

بدل كتابة:

```python
x = x + 5
```

نكتب:

```python
x += 5
```

## 3. عوامل المقارنة

تعيد `True` أو `False`.

```python
==  يساوي
!=  لا يساوي
>   أكبر من
<   أصغر من
>=  أكبر من أو يساوي
<=  أصغر من أو يساوي
```

## 4. العوامل المنطقية

```python
and
or
not
```

تستخدم لدمج أو عكس الشروط.

## 5. عوامل الهوية

```python
is
is not
```

تسأل: هل المتغيران يشيران إلى نفس الكائن في الذاكرة؟

## 6. عوامل العضوية

```python
in
not in
```

تسأل: هل القيمة موجودة داخل قائمة أو نص أو Tuple؟

## 7. عوامل البت

```python
&
|
^
~
<<
>>
```

هذه مهمة أكثر في المستويات المتقدمة مثل التعامل مع الأنظمة أو التشفير.

## أخطاء مهمة

- `=` للإسناد.
- `==` للمقارنة.
- `/` يعطي عددًا عشريًا.
- `//` يعطي قسمة صحيحة.
- `is` ليس بديلًا دائمًا عن `==`.
