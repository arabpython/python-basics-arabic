# ملاحظات الدرس

## ما معنى الشرط؟

الشرط هو سؤال يطرحه البرنامج، والنتيجة تكون غالبًا `True` أو `False`.

```python
age = 20
print(age >= 18)
```

## استخدام if

```python
age = 20

if age >= 18:
    print("مسموح لك بالدخول")
```

## استخدام else

```python
age = 15

if age >= 18:
    print("مسموح لك بالدخول")
else:
    print("غير مسموح لك بالدخول")
```

## استخدام elif

```python
grade = 85

if grade >= 90:
    print("ممتاز")
elif grade >= 80:
    print("جيد جدًا")
elif grade >= 70:
    print("جيد")
else:
    print("تحتاج إلى تحسين")
```

## عوامل المقارنة

`==`, `!=`, `>`, `<`, `>=`, `<=`

## العوامل المنطقية

`and` يجب تحقق الشرطين، و`or` يكفي تحقق شرط واحد، و`not` يعكس الشرط.

## أخطاء شائعة

- نسيان النقطتين `:`.
- استخدام `=` بدل `==`.
- نسيان المسافة البادئة.
- كتابة شروط متداخلة كثيرة تجعل الكود صعب القراءة.
