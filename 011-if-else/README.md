## فكرة الدرس

في هذا الدرس يتعلم الطالب كيف يجعل البرنامج يتخذ قرارًا باستخدام الشروط. بدل أن ينفذ البرنامج كل الأوامر دائمًا، يمكننا استخدام `if`, `elif`, و `else` لتنفيذ كود معين حسب نتيجة الشرط.

## ماذا ستتعلم؟

- معنى الشرط في البرمجة.
- الفرق بين `True` و `False`.
- استخدام `if`, `else`, و `elif`.
- أهمية المسافات البادئة Indentation داخل الشروط.
- استخدام عوامل المقارنة مثل `==`, `!=`, `>`, `<`, `>=`, `<=`.
- استخدام `and`, `or`, و `not`.
- معرفة هل الرقم زوجي أم فردي.
- التحقق من كلمة المرور.
- استخدام `input()` مع الشروط.
- كتابة شروط متداخلة Nested if.
- تجنب أخطاء شائعة مثل نسيان `:` أو استخدام `=` بدل `==`.
