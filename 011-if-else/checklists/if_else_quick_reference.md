# مرجع سريع لشروط if و else في Python

## if

```python
if condition:
    print("True")
```

## if و else

```python
if condition:
    print("True")
else:
    print("False")
```

## if و elif و else

```python
if grade >= 90:
    print("ممتاز")
elif grade >= 80:
    print("جيد جدًا")
else:
    print("تحتاج إلى تحسين")
```

## عوامل المقارنة

```python
==

```

## العوامل المنطقية

```python
and
```

## أخطاء شائعة

- نسيان النقطتين `:`.
- استخدام `=` بدل `==`.
- نسيان المسافة البادئة.
- وضع `else` بدون `if`.
- الإفراط في Nested if بدون حاجة.
- نسيان تحويل input إلى رقم عند المقارنة الرقمية.
