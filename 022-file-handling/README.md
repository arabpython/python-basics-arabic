## فكرة الدرس

في هذا الدرس يتعلم الطالب كيف يجعل برنامج Python يتعامل مع ملفات نصية خارجية، بدل أن يطبع النتائج فقط على الشاشة.

سيتعلم الطالب كيف يفتح ملفًا باستخدام `open()`، وكيف يقرأ محتواه، ويكتب داخله، ويضيف أسطرًا جديدة دون حذف القديم، ولماذا نستخدم `with open(...)` بدل فتح الملف وإغلاقه يدويًا.

## ماذا ستتعلم؟

- معنى التعامل مع الملفات في Python.
- فتح ملف باستخدام `open()`.
- إغلاق الملف باستخدام `close()`.
- استخدام `with open(...)` كطريقة أفضل وأكثر أمانًا.
- قراءة ملف كامل باستخدام `read()`.
- قراءة سطر واحد باستخدام `readline()`.
- قراءة كل الأسطر كقائمة باستخدام `readlines()`.
- قراءة الملف سطرًا سطرًا باستخدام `for line in file`.
- كتابة نص داخل ملف باستخدام `write()`.
- كتابة أكثر من سطر باستخدام `\n`.
- الفرق بين أوضاع الفتح `r`, `w`, `a`, `x`.
- الفرق بين `w` الذي يمسح المحتوى القديم و`a` الذي يضيف في النهاية.
- استخدام `strip()` لتنظيف الأسطر المقروءة.
- التعامل مع ملفات عربية باستخدام `encoding="utf-8"`.
- فهم خطأ `FileNotFoundError`.
- مشاريع تدريبية: حفظ أسماء الطلاب، عرض الطلاب، برنامج ملاحظات، برنامج مهام.
