# مرجع سريع لأنواع البيانات في بايثون

## الأنواع المهمة للمبتدئ

| النوع | مثال | الاستخدام |
|---|---|---|
| `str` | `"Hello"` | النصوص |
| `int` | `20` | الأعداد الصحيحة |
| `float` | `20.5` | الأعداد العشرية |
| `complex` | `3 + 5j` | الأعداد المركبة |
| `list` | `[1, 2, 3]` | قائمة قابلة للتغيير |
| `tuple` | `(1, 2, 3)` | قائمة غير قابلة للتغيير |
| `range` | `range(6)` | نطاق أرقام |
| `dict` | `{"name": "Ali"}` | مفتاح وقيمة |
| `set` | `{1, 2, 3}` | عناصر غير مكررة |
| `frozenset` | `frozenset({1, 2})` | مجموعة غير قابلة للتغيير |
| `bool` | `True` | صح أو خطأ |
| `bytes` | `b"Hello"` | بيانات ثنائية |

## أسئلة تساعدك تختار النوع

- هل القيمة نص؟ استخدم `str`.
- هل القيمة رقم صحيح؟ استخدم `int`.
- هل فيها فاصلة عشرية؟ استخدم `float`.
- هل تحتاج عناصر مرتبة قابلة للتغيير؟ استخدم `list`.
- هل تحتاج عناصر مرتبة غير قابلة للتغيير؟ استخدم `tuple`.
- هل تحتاج مفاتيح وقيم؟ استخدم `dict`.
- هل تريد منع التكرار؟ استخدم `set`.
- هل القيمة صح أو خطأ؟ استخدم `bool`.
