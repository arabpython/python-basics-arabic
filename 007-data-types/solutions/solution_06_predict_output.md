# حل تمرين 06

الناتج سيكون أنواع القيم التالية:

```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'list'>
<class 'tuple'>
<class 'dict'>
<class 'set'>
<class 'bool'>
```

## السبب

- `"10"` نص لأنه بين علامات اقتباس.
- `10` عدد صحيح.
- `10.0` عدد عشري.
- `["Python"]` قائمة.
- `("Python",)` صف Tuple يحتوي عنصرًا واحدًا.
- `{"course": "Python"}` قاموس لأنه يحتوي مفتاح وقيمة.
- `{"Python"}` مجموعة Set.
- `False` قيمة منطقية.
