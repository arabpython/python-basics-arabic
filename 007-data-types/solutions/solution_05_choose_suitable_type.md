# حل تمرين 05

اختيارات مناسبة:

```python
student_name = "Ali"                         # str
student_age = 20                             # int
student_grades = [80, 90, 75]                # list
is_passed = True                             # bool
student_info = {"name": "Ali", "age": 20, "city": "Amman"}  # dict
```

## السبب

- الاسم نص، لذلك نستخدم `str`.
- العمر رقم صحيح، لذلك نستخدم `int`.
- الدرجات متعددة، لذلك `list` مناسبة.
- النجاح أو الرسوب قيمة منطقية، لذلك `bool`.
- بيانات الطالب ككيان واحد تناسبها `dict`.
