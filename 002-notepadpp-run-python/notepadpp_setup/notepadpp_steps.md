# خطوات تشغيل بايثون من Notepad++

## 1. افتح Notepad++

افتح برنامج Notepad++ من جهازك.

## 2. اختر لغة Python

من القائمة اختر:

```text
Language > P > Python
```

أو من تبويب اللغات ابحث عن Python.

## 3. اكتب الكود

مثال:

```python
print("Hello, World!")
```

## 4. احفظ الملف

احفظ الملف باسم:

```text
python.py
```

المهم أن ينتهي الاسم بـ `.py`.

## 5. أضف أمر التشغيل

من القائمة اختر:

```text
Run > Run...
```

ثم الصق الأمر:

```bash
python -i "$(FULL_CURRENT_PATH)"
```

## 6. احفظ الاختصار

يمكنك اختيار اسم مثل:

```text
Run Python
```

واختيار اختصار مثل:

```text
ALT + Z
```

## 7. شغل الكود

اضغط الاختصار الذي حفظته، وسيظهر ناتج الكود.
