# ملاحظات الدرس

## لماذا نستخدم Notepad++؟

Notepad++ محرر نصوص خفيف يمكن استخدامه لكتابة أكواد بايثون، خصوصًا في بداية التعلم.

## أهم خطوة في الدرس

يجب حفظ الملف بامتداد `.py` حتى يعرف النظام أن الملف خاص بلغة بايثون.

مثال صحيح:

```text
python.py
```

مثال غير مناسب:

```text
python.txt
```

## أمر التشغيل داخل Notepad++

استخدم الأمر التالي داخل نافذة Run في Notepad++:

```bash
python -i "$(FULL_CURRENT_PATH)"
```

هذا الأمر يعني: شغل ملف بايثون الحالي الذي تعمل عليه داخل Notepad++.

## تذكير

بعد تعديل الكود، احفظ الملف ثم شغله مرة أخرى.
