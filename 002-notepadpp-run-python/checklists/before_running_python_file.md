# قائمة فحص قبل تشغيل ملف بايثون

راجع هذه النقاط إذا لم يعمل الكود:

- هل تم تثبيت Python على الجهاز؟
- هل اسم الملف ينتهي بـ `.py`؟
- هل حفظت الملف بعد آخر تعديل؟
- هل كتبت أمر التشغيل بشكل صحيح؟
- هل النصوص داخل `print()` بين علامتي تنصيص؟
- هل اخترت لغة Python داخل Notepad++؟
- هل تستخدم الاختصار الصحيح مثل `ALT + Z`؟
