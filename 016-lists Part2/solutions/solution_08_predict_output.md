# حل تمرين 08

الناتج هو:

```text
a
c
d
4
['x', 'b']
```

## السبب

القائمة بدأت هكذا:

```python
["a", "b", "c"]
```

ثم:

- `append("d")` أضافت `d` في النهاية.
- `insert(1, "x")` أضافت `x` في الفهرس 1.
- `pop()` حذف آخر عنصر وهو `d`.
- العنصر الأول هو `a`.
- آخر عنصر بعد الحذف هو `c`.
- طول القائمة أصبح 4.
- `items[1:3]` يرجع العنصرين عند الفهرس 1 و 2.
