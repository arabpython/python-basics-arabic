# ملاحظات الدرس

## الفكرة الأساسية

في بايثون نستخدم الأمر `print()` عندما نريد عرض نص أو رقم على الشاشة.

مثال:

```python
print("Hello, World!")
```

الناتج:

```text
Hello, World!
```

## لماذا نضع النص بين علامتي تنصيص؟

لأن بايثون تحتاج أن تعرف أن هذا الكلام نص عادي وليس أمرًا برمجيًا.

صحيح:

```python
print("Arab Python")
```

خطأ:

```python
print(Arab Python)
```

## تمارين بسيطة

1. اطبع اسمك.
2. اطبع اسم موقع بايثون العرب.
3. اطبع ثلاث جمل في ثلاثة أسطر.
4. أصلح كودًا ناقصًا أو فيه خطأ بسيط.
