# ملاحظات الدرس

## ما هي التعليقات؟

التعليقات هي نصوص داخل ملف بايثون لا يتم تنفيذها.  
يستخدمها المبرمج لشرح الفكرة أو تذكير نفسه بشيء مهم.

## تعليق السطر الواحد

```python
# هذا تعليق
print("Hello, World!")
```

بايثون ستنفذ `print` فقط، وتتجاهل التعليق.

## تعليق في نهاية السطر

```python
age = 18  # عمر المستخدم
```

هذه الطريقة مفيدة للتوضيح السريع، لكن لا تجعل التعليق طويلًا جدًا.

## تعطيل كود مؤقتًا

```python
print("This line will run")
# print("This line will not run")
print("This line will run too")
```

نستخدم هذا الأسلوب أثناء التجربة أو تصحيح الأخطاء.

## التعليقات متعددة الأسطر

الطريقة المفضلة:

```python
# هذا تعليق طويل
# مكتوب على أكثر من سطر
# وكل سطر يبدأ بعلامة #
```

## ملاحظة عن Triple Quotes

يمكن أن ترى بعض المبرمجين يستخدمون:

```python
"""
هذا نص متعدد الأسطر
قد يستخدم كتعليق مؤقت
"""
```

لكن تقنيًا هذا ليس تعليقًا حقيقيًا، بل String متعدد الأسطر لم يتم استخدامه.

## قاعدة مهمة

التعليق الجيد يشرح "لماذا" كتبنا الكود بهذه الطريقة، وليس فقط "ماذا" يفعل السطر الواضح.
