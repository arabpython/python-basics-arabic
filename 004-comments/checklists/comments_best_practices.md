# قائمة أفضل ممارسات التعليقات في بايثون

استخدم هذه القائمة عند كتابة التعليقات:

- هل التعليق يضيف معنى حقيقيًا؟
- هل يشرح السبب وليس الشيء الواضح؟
- هل التعليق قصير وواضح؟
- هل التعليق بجانب السطر لا يجعل السطر طويلًا جدًا؟
- هل يمكنك تحسين اسم المتغير بدل كتابة تعليق؟
- هل استخدمت التعليق لتعطيل كود مؤقتًا فقط؟
- هل حذفت التعليقات القديمة التي لم تعد صحيحة؟
- هل تجنبت كتابة تعليق لكل سطر؟

## تعليق ضعيف

```python
x = x + 1  # زيادة x بواحد
```

## تعليق أفضل

```python
x = x + 1  # تعويض فرق الترقيم لأن النظام يبدأ العد من الصفر
```
