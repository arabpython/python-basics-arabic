# حل تمرين 06

الناتج المنطقي سيكون:

```text
3
True
False
4
```

## السبب

- المجموعة تبدأ بـ `{"a", "b", "a", "c"}` لكن التكرار يُحذف، لذلك عدد العناصر `3`.
- `"b" in items` نتيجتها `True`.
- `"x" in items` نتيجتها `False`.
- بعد إضافة `"d"` يصبح العدد `4`.
- `discard("x")` لا يسبب خطأ حتى لو لم يكن العنصر موجودًا.
