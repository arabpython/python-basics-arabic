# ملاحظات الدرس

## ما هي Set؟

الـ `set` هي مجموعة من العناصر تُكتب داخل أقواس معقوفة:

```python
fruits = {"apple", "banana", "cherry"}
```

## أهم خصائص Sets

- غير مرتبة، لذلك لا تعتمد على ترتيب العناصر.
- لا يمكن الوصول إلى عناصرها باستخدام Index.
- لا تسمح بتكرار نفس القيمة.

## مثال على منع التكرار

```python
fruits = {"apple", "banana", "cherry", "apple"}
print(fruits)
```

سيظهر `apple` مرة واحدة فقط.

## لا تستخدم Index مع Set

```python
fruits = {"apple", "banana", "cherry"}
print(fruits[0])  # خطأ
```

لأن `set` لا تدعم الوصول بالفهرس.

## دوال مهمة

```python
add()                   # إضافة عنصر واحد
update()                # إضافة عدة عناصر
remove()                # حذف عنصر، ويعطي خطأ إذا لم يكن موجودًا
discard()               # حذف عنصر بدون خطأ إذا لم يكن موجودًا
pop()                   # حذف عنصر عشوائي
clear()                 # تفريغ المجموعة
union()                 # إنشاء مجموعة جديدة من مجموعتين
intersection()          # العناصر المشتركة
intersection_update()   # تعديل المجموعة لتحتفظ بالمشترك فقط
symmetric_difference()  # العناصر غير المشتركة
```

## متى أستخدم Set؟

استخدم `set` عندما تريد:

- منع تكرار القيم.
- التحقق بسرعة من وجود عنصر.
- تنفيذ عمليات الاتحاد والتقاطع.
- تنظيف قائمة من القيم المكررة.

ولا تستخدمها عندما يكون ترتيب العناصر مهمًا أو عندما تحتاج الوصول إلى العناصر باستخدام Index.
